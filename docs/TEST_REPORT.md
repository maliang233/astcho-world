# 验证说明

测试使用独立临时目录、合成消息、本地模型端点和测试WebSocket。SDK集成测试实际启动已安装的 `deepseek-harness-sdk==0.2.1rc2`，不拿自写循环代替SDK。

B站独立运行环境属于可选安装；没有 `var/runtimes/bilibili/bin/python` 时，对应的独立SDK登录测试会跳过。其余B站合成接口测试照常执行。

## 运行

```bash
python -m pytest
python -m astcho_world check-baseline
node --test tests/dsh/*.test.cjs tests/web/*.test.cjs
```

如有原项目的本地工作区，可额外核对：

```bash
python -m astcho_world check-baseline --original ../astcho-github
```

`docs/legacy-baseline.json` 保留采集时的本地来源、提交及文件哈希；原项目包含当时尚未提交的改动，不能直接拿远端HEAD代替。该文件及受保护源文件未因公开仓库而重建。

## 覆盖范围

- App协议、独立worker、停止/重启、故障隔离、操作身份、防重复与未知回执。
- 真实SDK的工具发现、原生网页/提醒/Skill、同Session恢复、压力压缩与完整工具链。
- QQ反向WS、通知与主动阅读、未读水位、固定快照、管理员分流、主体回复及分段回执。
- 图片初步理解与按问题细看，B站资料、字幕、画面、扫码状态恢复及分享链路。
- 活动跨回合、有限等待、原文校验、本地索引、近期条数与按需检索。正常活动、迁移、维护及恢复都不再调用活动摘要模型。
- 可选自留文字与事实回执分开，未知写入保留独立账本；写盘或索引失败时保留原上下文。
- 降低周期频率后，通知、提醒投递和管理员私聊仍直接唤醒，睡眠/忙碌/等待不积压周期机会。
- 用量归一化、计价、缓存覆盖率、分页和异步页面状态。

## 已知失败

`tests/legacy/test_prompts.py::test_planner_prompt_preserves_decision_contract` 的一处文案期望与原本地模板不一致。这是迁入前已有的失败，原模板和原断言都保留。不能为了让测试全绿而改写聊天prompt。

自动测试验证协议、状态和模型实际收到的信息；合成模型的脚本不能证明星回已经能在真实聊天中做出合适判断，也不能代替长期费用观察。

`docs/screenshots/` 使用合成演示数据。实际账号、聊天、凭证、用量明细、会话日志及部署备份不进入仓库。
