# 评论与分享的克制（2026-10-29）

用户授权：站内评论克制，想让管理员看优先私聊 QQ；群分享需要明确受众联系，避免连续打扰。浏览不要求对外产出。

## 模型选择

新增环境提示 `prompts/social_actions.md`，独立于受保护的原聊天、视觉 prompt 和人格原文。评论工具仍可选择使用，但提醒先了解实际内容与已有讨论，有具体问题、补充或独立观点时才考虑；不为赞美、复述或留下浏览痕迹发表评论。没有新评论格式、另一轮润色模型、兴趣评分或每日互动指标。

分享优先考虑配置管理员私聊。群分享前读近期聊天，并判断内容与具体受众的联系。`audience_reason` 是内部选择依据，不会拼入 QQ 正文；不要为满足参数编造关联。是否值得分享仍由主体判断，程序不打“内容质量分”。

## 近期状态

QQ 的 `share_context` 提供管理员私聊入口，以及指定接收人的最近发送时间、24小时内确认发送次数、最近3条链接/自己附言预览、未知回执数量。环境元数据会提供最近行动过的目标（最多30个，另含配置管理员）；主动读取群聊也返回该群分享状态。

只读取自己的分享台账，不读取私聊收件箱或未读正文。次数、时间及冷却到期都是事实，不代表接收人已读、喜欢，也不构成待办或新的发送任务。不会为暂缓分享建立提醒或排队补发。

## 群主动分享保护

默认：

- 同一群的主动链接分享至少间隔600秒，从确认发送时间计；未知尝试按实际尝试时间保留间隔。
- 需该群最近300秒内的实际观察。观察后若已有新的群友消息，先主动读取再判断；检查只返回新消息数量，不旁路附带正文。新建一份旧页观察也不能代替当前上下文。
- 需要非空内部受众理由。目标、上下文或发送条件不符合时返回 `not_sent`，不调用投递、不预留待发送任务。
- 相同意图重试优先返回原回执，即使当前观察已过期或正在冷却。换意图ID不能绕过群间隔。
- 同一接收人同资源有未知回执时，阻止换意图盲目重发。B站同BV视频的时间参数、追踪参数变化仍识别为同一资源。

保护仅针对主动 `share_link` 入口。原正常群聊、私聊链路和发送后处理保持原样；环境明确提醒不得借普通回复、其他目标或其他工具规避主动分享保护。管理员私聊无需伪造来信或读取私聊收件箱，不施加群间隔限制；近期历史仍供主体判断频率。

可在 QQ App 的私有配置调整：

```json
{
  "sharing": {
    "group_interval_seconds": 600,
    "group_context_max_age_seconds": 300
  }
}
```

这是发送条件，不是每日配额或发言目标。`not_sent` 表示本次确实没有发送；不知道是否送达的旧尝试继续保持 unknown。不同资源、不同群的相关性仍由主体判断，工具不能保证模型审美或评论质量。

## 持久化与验证

分享台账增加实际时间与原请求，用命名列插入以兼容旧库。旧成功记录仅从真实已发消息恢复时间；旧 unknown 不补造时间或回执。迁移可重复执行，原意图和消息ID不变。

验证覆盖：合成投递、受控时钟、跨重启、过期/错群/旧锚点/新未读、管理员私聊、普通私聊拒绝、未知回执及BV时间链接变体、旧表迁移；真实 DSH SDK读取视频、查看分享状态、打开群上下文、再经测试反向WS发送链接。开发者不进行真实B站评论或QQ试发。
