# 环境上下文维护

2026-10-28，按用户要求暂缓显式输入 token 预算：没有新增总输入上限、固定历史条数或按长度强行截断。原有模型容量、输出参数与活动步数机制不变。以下只作用于环境运行器，不改变原聊天的 prompt、输入组织或模型参数。

## 过期状态与通知

每步提供最新 `world.runtime`。旧的、由 World 产生的 runtime 快照经 DSH 的持久 surface replacement 替换为空 developer 节点，不再产生模型消息；原日志完整保留。应用正文、普通输出、工具调用与回执不按此规则删除。重启后继续按同一规则处理旧快照。

替换发生在固定版本 DSH 的 `agent/request` 扩展点，处于合法的 open step 内，通过 Session 写入正式替换事件；没有修改冻结的请求消息或绕过持久日志。该兼容接口已被上游标为弃用，升级 SDK 时必须重新验证。

唤醒事件只重复提供新送达通知的正文；较早通知保留 ID，仍可通过 `world_notifications` 主动查看。状态去重会改变请求前缀，提供商的前缀缓存命中可能下降；这不等同于费用优化。

## 压缩与操作状态

继续复用 DSH 的范围选择、工具调用/结果配对、缩短验证、压缩事务和完整日志。自定义其 `summarize` 扩展点，模型调用仍通过 DSH `ctx.llm.stream`。插件卸载时恢复原实现。

新增独立的 `prompts/compaction.md`，仅整理已观察事实、实际选择、有依据的未完成意图与未知之处；不使用默认编程交接提示，不生成生活计划。DSH 默认 checkpoint 中要求继续任务的包装在下一次正常请求前，另以可回放的持久替换换为经历摘要说明。身份/环境 system 提示及私人身份原文不参与压缩。

摘要必须是指定结构，每条引用至少一个本段实际输入的 DSH 消息 ID；无效 JSON、无效引用、非文本输出、工具调用、截断或失败都不能落入摘要。摘要来源 ID 和原始内容仍在 DSH 日志中。引用/结构校验不能证明每句话的语义正确，真实模型的长期摘要质量仍需验证；摘要明确标为可能有误，不自动转为个人记忆。

操作回执单独处理：从本段实际输入提取操作 ID，按 World 原始账本附上写入结果，不让摘要模型编写回执。每步最新状态还提供 `running/unknown` 写操作的精确 ID、应用、工具和状态，不自动重试或将其转成待办。

修正了 DSH 默认摘要预留 65536 与当前声明窗口 65536 不相容的配置：摘要预留和输出沿用环境模型原有输出额度，未新增输入硬上限。自动压缩仍按 DSH 的模型容量策略判断。若不能缩短（例如保留区过大或摘要比选中段更长），该次不替换选中历史，记录失败；先前已成功落盘的压缩保留。

`await agent.compact()` 提供显式维护入口，使用同一个 SDK、会话和压缩引擎，不做新的主体决策、不投递通知。当前没有 Web 写入按钮或定时整理脚本。

## 主动回看经历

新增 `world_recall`：可搜索、分页预览已送达观察和自身行动；用 `event_seq` 读取单条原始记录。预览明确为预览，不假装已读完整正文。

范围仅包括 `observation.created`、原始工具选择/结果、普通环境输出与活动状态。排除未送达通知、原始 App 数据库、管理员调试日志、密钥/身份调试输入，以及回看工具自身的嵌套结果。通知被忽略后，已经送达的记录仍属于可回看的经历；忽略不等于已经阅读群上下文。工具不会自动唤醒、形成记忆或安排活动。

## Web 与日志

开发者后台新增“模型上下文”。列表区分环境决策/经历压缩、显示消息/工具数、提供商报告的 token 用量与压缩落盘结果；点击查看完整输入。角色分布使用字符统计，明确不冒充 tokenizer 精确计数。不虚构未报告用量，也不重建之前未记录的请求。

记录的是 DSH 实际发给适配层的输入；提供商的角色、工具、图片等协议转换可能不同，不称作原始 HTTP 请求。相同消息和工具以 SHA-256 内容片段复用，避免每轮重复存储整份历史；可无损展开，没有输入截断。片段和请求索引均在私有 World 数据库，不进入经历回看工具。

所有查询要求现有 Web 认证并沿用敏感字段遮蔽；浏览不写已读、观察、通知或操作状态。

## 验证

真实安装的 DSH SDK/原生进程 + 本机合成模型：状态去重及重启、实际输入记录、有效压缩及重启、引用错误/无效 JSON 拒绝、原文可回看、精确 unknown 回执、自动压力下不能安全缩短时保留历史并继续。另验证回看信息边界、Web 鉴权/遮蔽/只读和日志片段无损去重。浏览器已检查合成输入列表、用途/用量和完整请求详情。

没有真实模型或 QQ 调用，没有把现有服务切换为在线主体。长期真实模型摘要质量、不同提供商计数误差与超大不可分割工具结果仍需验证。
