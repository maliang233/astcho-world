# 活动上下文与缓存命中率

2026-10-29，用户授权改善缓存复用并增加命中率指标。只调整新环境上下文及管理统计，原聊天模板、人格、采样参数和普通私聊链路不改。

## 上下文布局

旧实现每次模型步骤前用空developer消息替换过去的world.runtime，再追加完整当前状态，会改动历史前缀。现在同一运行回合先追加完整snapshot，之后仅追加发生变化的顶层字段update。未出现字段沿用上一状态，出现的字段整体替换，null和空列表用于清除；新通知消失也会明确清除。状态ID、run_id和上一状态ID用于核验可见链，历史输入不就地改写。运行回合切换或原生压缩导致状态链不完整时，补回完整snapshot。

已结束活动仍在原边界先归档经历、生成或复用简述，再通过SDK事务隐藏整段详细历史；失败保留原文。最近10条索引、完整回看、未知操作账本、有限等待及睡眠机制不变。长活动仍可原生压力压缩，无新增输入预算、固定截断或额外整理调用。

用户随后因费用授权取消独立活动摘要模型，现改为本地事实索引及可选world_finish自留文字，已有有效简述直接复用；原先的摘要system/user请求不再产生，历史计费记录仍保留。工具实际增加、归档和压力压缩仍可能改变前缀，不保证缓存永远命中。提供商规则见[DeepSeek说明](https://api-docs.deepseek.com/guides/kv_cache/)。

## 指标口径

命中率 = 同时有合法输入总量和缓存命中量的调用中，命中token之和 / 输入token之和。按token加权，不平均各次百分比；输出不参与。输入总量含命中部分，DSH/OpenAI继续使用已有归一化。

总计、用途/模型/服务商/App/活动分组及单次明细提供cache对象，含hit_rate、已知输入/命中token、已知/缺失调用数和complete标记。未报告或非法明细不当成0%，展示覆盖范围；实际零命中显示0.0%，无可计算输入显示“—”。汇总使用完整筛选范围，不随明细分页变化。

activity_summary单列为“活动摘要”。旧版误归environment的调用，仅在原始事件与request_id精确对应时修正派生用途，保留usage_classification_repairs审计。原事件、用量、费用、状态及历史价格不改，不重新计价。

## 验证

真实SDK+本地合成模型验证连续步骤及同Session重启后，前次请求消息仍为下次的逐字前缀；状态仅追加，不生成旧runtime替换事务。状态链缺口、通知清除、空操作列表、归档及压缩恢复有独立检查。不可缩短摘要使用显式大输出验证失败保留历史。

指标覆盖加权、零/未知/非法计数、筛选/分页一致性和修正审计。Python全量410通过、1项既有Planner断言失败；JS状态、格式、页面控制16项通过。浏览器合成数据确认指标、覆盖范围和摘要分类，截图 screenshots/cache-hit-metrics.png。

私有数据库副本预演修正249次旧摘要，逐行验证除purpose外所有调用字段及源事件不变、重复执行无变化。实际命中率提升需从上线后提供商回执观察，结构测试不替代服务商缓存实测。
