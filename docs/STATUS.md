# 当前状态

目前是自用中的实验项目，主要在 macOS ARM64 上验证。首次使用从 [README](../README.md) 开始；配置示例不会包含实际使用的账号、人格或日程。

## 已接入

| 部分 | 当前实现 |
| --- | --- |
| 主体 | 固定版本的 DSH Python SDK、持久会话、工具循环与合法历史投影 |
| App | 独立子进程、Manifest、按需展开工具、操作回执与数据目录 |
| QQ | NapCat 反向 WS、概率通知、免打扰、未读概况、主动读取与搜索、看图、主体直接回复 |
| 私聊 | 配置管理员进入同一主体；非管理员使用原聊天路径，不开放环境工具 |
| Bilibili | 扫码登录、推荐与搜索、资料/字幕/画面读取、点赞/收藏/评论、普通链接分享 |
| 网页与知识 | DSH 搜索、URL读取、持久提醒和按需Skill |
| 活动 | 跨回合继续、有限等待、原文归档、本地事实索引和按编号回看 |
| 唤醒 | 通知、管理员私聊、提醒及可选日程周期；默认范围约2～10分钟，睡眠停周期 |
| Web | 状态、日程、通知、上下文、用量与缓存、账号管理和立绘 |

正常文本不会自动发送到任何应用。需要发言或站内互动时，主体明确调用对应工具。活动结束不另调用模型生成摘要；已有摘要保留，后续由本地事实和可选自留文字组成索引。

## 还没有做完

- 没有可点击、处理登录态和执行页面JavaScript的浏览器，也没有通用电脑操作入口。
- 视频理解依赖实际可取得的资料、字幕和画面，尚未接入语音转写，不能当作完整观看。
- 原聊天源码保留，但新环境没有搬回所有旧后台学习、跟风和管理反馈入口。
- App尚无通用安装市场、自动升级或统一后台Job服务；子进程不是系统安全沙箱。
- Windows运行锁尚未适配。其他系统及SDK版本需要单独验证。
- 真实聊天表现仍在调整。原文、参数和后处理的复用不等于表现完全一致。
